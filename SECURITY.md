# Sicurezza / Security

Il server MCP locale e le app gestiscono la chiave per automazioni di Jobdossiers e dati decifrati delle candidature: le segnalazioni di sicurezza sono benvenute.

## Come segnalare

Non aprire una issue pubblica. Usa **Security → Report a vulnerability** in questo repository (segnalazione privata di GitHub). Indica la versione o il commit, i passi per riprodurre il problema e l'impatto. Non includere chiavi, token o dati reali di candidature.

Ti rispondiamo appena possibile e ti teniamo aggiornato fino alla correzione. Se lo desideri, ti citiamo nelle note di rilascio.

## Perimetro

- Questo repository: server MCP locale (`src/`), app per Mac (`mac/`) e Windows (`win/`), script di build e workflow.
- Il portale jobdossiers.ch e il connettore remoto non sono in questo repository: segnalali comunque qui, li inoltriamo noi.

---

Please do not open public issues for security problems. Use **Security → Report a vulnerability** in this repository to report privately, with version or commit, steps to reproduce and impact. Never include keys, tokens or real application data.
